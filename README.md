# Motive Engine

Motive Engine is a life simulation engine for creating simulated indivuals.

## Minimum Requirements

### Development

- Swift 6.3+

### Deployment

| Target  | Version |
| ------- | ------- |
| macOS   | 10.13   |
| Windows | 10      |
| Ubuntu  | 20.04   |
| Debian  | 12      |
| Fedora  | 39      |
